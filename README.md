# AWS Cloud Computing Minor Projects

A growing portfolio of hands-on AWS cloud computing minor projects completed as part of my B.Tech CSE coursework.

This repository is updated weekly as new projects and cloud skills are introduced.

## Projects

### 01. Static Website Hosting Using EC2 and S3 (Nginx)

Hands-on deployment of an Nginx web server on Amazon EC2 with S3 used for backup storage and IAM-based instance access.

**Key concepts:** EC2, Amazon Linux, Nginx, S3, IAM roles, security groups, SSH, AWS CLI

[Open Project](./01-ec2-s3-nginx/)

### 02. Secure Multi-Tier Web Application Network on AWS

Designed a VPC with public and private subnets, route tables, security groups, NAT Gateway and a bastion-based access path to a private database server.

**Key concepts:** VPC, subnets, routing, Internet Gateway, NAT Gateway, security groups, NACLs, EC2, Nginx, MariaDB, bastion host

[Open Project](./02-secure-multi-tier-vpc/)

### 03. AWS IAM - Roles, Policies & Permission Best Practices

Implemented IAM users, groups, custom policies, managed policies, an EC2 IAM role, MFA and permission validation using controlled access tests.

**Key concepts:** IAM users, groups, policies, least privilege, roles, MFA, permission testing

[Open Project](./03-aws-iam-security/)

## Repository Workflow

Every Friday: complete the new minor project.

Every Saturday or Sunday:

1. Create the new project folder.
2. Add a project README.
3. Add the final report PDF.
4. Add important screenshots and architecture diagrams.
5. Add useful commands or configuration files.
6. Update this top-level README.
7. Review screenshots and remove any secrets or credentials.
8. Commit and push the changes.
